** Diamond mountain release note
*** V1.3 2025.12.28 UI周りを中心に機能追加
**** コントロールパネルのフローティング化
- 見栄えの変更
  配色や構図を現代風に変更。
- 画面の専有域を縮小
- 「再表示」ボタンの追加
- 観測地情報の追加
  緯度、経度、標高を表示。現在disableにしてるが、可変にする予定。
**** コントロールパネルの折り畳み機能▲▼
  主に携帯電話向けに地図域を大きく表示するため、折り畳み式にする。
  地図域を有効利用するため、コントロールパネルを折り畳みにする。
**** 携帯電話画面での最適化
  入力域をスクロール式にして地図域を確保。
**** MAP画面のライン表示のクリアと再表示
  クリアボタンで可視域表示と日出・日没のラインをクリア・再表示可能にする。
**** その他、マイナな修正
- infomation域の表示内容を見直し
- 観測地ポップアップ情報の表示域見直し
- メッセージの内容見直し
