## V1.2 2025.12.22  V1系の機能追加

V1系の予定機能を追加。

* 観測地情報の表示
  高度、観測日、日出時刻、日没時刻、日出方角、日没方角、を追加。

* 山の動的登録・選択
  任意の山、地点を観測ターゲットに指定可能。

* 観測地点クリックで詳細情報表示
  ポップアップで観測地点でのダイヤモンド情報を表示。

* 日の出・日の入り方向の視覚化（青とオレンジの線）
  観測地点の日出、日没情報を破線ラインで可視化。

* 可視範囲の境界線表示（冬至・夏至の南限・北限）
  対象の山の観測可能範囲の目安（範囲が実際より狭い）を実線ラインで表示。

* 期間検索（別ウィンドウで一覧表示・CSV出力）
  指定された期間のダイヤモンド情報を別ウィンドウで表出力。CSV出力対応。
